# Бэклог

Предложения по развитию. Приоритет: **P1** — стоит сделать в первую очередь, **P2** — полезно, **P3** — по желанию.

## Генератор конфигов

- **P1. `port link-type trunk` перед `port trunk allow-pass vlan`.** На Huawei VRP команда allow-pass обычно не применяется, пока порт не переведён в trunk. Сейчас генератор этого не делает (поведение унаследовано от исходной версии). Варианты: всегда добавлять или включать флажком на странице генератора.
- **P1. Уникальность hostname у TOR.** Конфиги собираются в словарь по hostname, поэтому два коммутатора с одинаковым именем молча сольются в один конфиг. Нужен `UNIQUE` на `switches.hostname` (с миграцией) или хотя бы предупреждение.
- **P2. `vlan batch` вместо поштучного объявления.** `vlan batch 302 505` короче. Описания при этом всё равно задаются отдельными блоками `vlan N / description`.
- **P2. Не дублировать объявления VLAN на Core.** Если на одном Core несколько кластеров, блок `vlan … description … quit` повторяется для каждого кластера. Объявлять один раз в начале конфига Core.
- **P2. Конфиг удаления VLAN.** Режим «убрать VLAN»: `undo port trunk allow-pass vlan N` на интерфейсах и, по желанию, `undo vlan N`.
- **P3. Шаблоны команд.** Вынести команды в редактируемые шаблоны, чтобы подстраивать их под разные модели (CE / S-серии) без правки кода.
- **P3. Проверка имён интерфейсов** по шаблону (`GE`, `10GE`, `100GE`, `Eth-Trunk`, `GigabitEthernet…`) с предупреждением об опечатках.

## Парсер USG

- **P1. Автотесты на обезличенном конфиге.** Сделать небольшой синтетический `tests/sample_usg.txt` и pytest-тесты на парсинг (address-set, service-set, nat-policy, wildcard, range) и на поиск. Сейчас регрессии ловятся только руками.
- **P2. `source-address-exclude` / `destination-address-exclude`.** Сейчас исключения игнорируются, и правило может найтись по адресу, который в нём исключён.
- **P2. Поиск по порту/сервису и по имени правила**, а не только по IP.
- **P2. Поиск теневых и дублирующихся правил**: правило, полностью перекрытое вышестоящим, никогда не сработает.
- **P2. Порядок правил и «первое совпадение».** Показывать номер правила и помечать, какое сработает первым для указанного адреса.
- **P3. IPv6** (`ip address-set … type object` с IPv6, `source-address 2001:db8:: 64`).
- **P3. Детали service-set**: source-port, icmp-type. Сейчас выводится только destination-port.
