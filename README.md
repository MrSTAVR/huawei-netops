# Huawei Config Tool

Настольное приложение для сетевого инженера, который работает с оборудованием Huawei:

- **учёт сети** — Core-коммутаторы, кластеры и TOR-коммутаторы с их uplink- и серверными интерфейсами;
- **генератор конфигов** — команды VLAN и транков для выбранных кластеров сразу на все TOR и Core;
- **парсер Huawei USG** — по IP или подсети находит все `security-policy` и `nat-policy`, где этот адрес встречается, и выгружает результат в Excel.

Написано на Python и tkinter. Из внешних зависимостей только `openpyxl` (для Excel). Данные хранятся в локальном SQLite.

## Возможности

### Сеть
Дерево `Core → кластер → TOR` с поиском по hostname, IP и кластеру. Панель деталей показывает подключения, uplink и серверные порты. Работает правая кнопка мыши (добавить TOR в кластер, дублировать TOR), двойной щелчок открывает редактирование, Delete удаляет. Кластеры без коммутаторов показаны отдельной группой.

### VLAN
Общая база VLAN (1–4094) с описаниями, из которой выбираются VLAN для генерации.

### Генератор
Отметьте кластеры и VLAN, и предпросмотр с подсветкой обновится сразу. Для каждого TOR генерируются объявления VLAN, транки на серверных интерфейсах и uplink. Для каждого Core генерируются транки на интерфейсах в сторону TOR. Результат можно скопировать, сохранить одним файлом или по файлу на коммутатор.

Пример вывода для одного TOR:

```
! === Кластер Cluster-A ===
vlan 302
  description APP_prod
  quit
interface 10GE1/0/1
  port trunk allow-pass vlan 302
  quit
interface 100GE1/0/49
  port trunk allow-pass vlan 302
  quit
```

### Парсер USG
Откройте выгрузку `display current-configuration` с межсетевого экрана Huawei USG, введите IP (`10.0.0.5`) или подсеть (`10.0.0.0/24`):

- раскрываются вложенные `address-set` (object и group), `range` и wildcard-маски;
- раскрываются пользовательские `service-set` и встроенные сервисы USG (`dns`, `https`, `rdp`…) до протокола и портов;
- для `nat-policy` показывается адрес трансляции (`address-group` или easy-ip);
- есть фильтр по зоне, выбор стороны (SRC / DST / обе) и опция «учитывать any» (правила без адресов);
- результат можно отфильтровать и отсортировать, под таблицей показан полный текст выбранного правила, Ctrl+C копирует строки;
- экспорт в `.xlsx`: deny-правила подсвечены, есть автофильтр и закреплённая шапка.

Для подсети ищутся правила, которые с ней **пересекаются**, а не только те, что содержат её целиком.

## Установка и запуск

Нужен Python 3.10+ (проверялось на 3.14) под Windows. На Linux и macOS тоже должно работать, но не проверялось.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python gui.py
```

При первом запуске рядом с программой создаются `switches.db` и `settings.json` (последняя вкладка и последний открытый конфиг USG).

## Сборка exe

```bash
pip install nuitka
python -m nuitka --standalone --enable-plugin=tk-inter --windows-console-mode=disable ^
    --output-filename=HuaweiConfigTool.exe gui.py
```

Готовая программа будет в `gui.dist\`. Файл `switches.db` создаётся рядом с exe.

## Структура

| Файл | Что внутри |
|---|---|
| `gui.py` | Главное окно, боковая навигация и четыре страницы |
| `theme.py` | Палитра, шрифты, стили ttk, общие виджеты (карточка, список с галочками, поле с подсказкой) |
| `dialogs.py` | Универсальная форма добавления и редактирования, валидаторы |
| `db.py` | SQLite: схема, миграции, CRUD, экспорт в JSON |
| `config_generator.py` | Генерация команд VLAN и транков для TOR и Core |
| `usg_parser.py` | Парсер конфигурации USG и поиск правил |
| `excel_export.py` | Выгрузка результатов парсера в Excel |

## Данные и безопасность

База (`*.db`), настройки и конфигурации устройств исключены из репозитория через `.gitignore`. Не коммитьте выгрузки с реальных устройств: в них адресация, имена и правила вашей сети.
